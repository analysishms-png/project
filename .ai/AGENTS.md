## Agent Collaboration

### Communication Protocol
1. Agents communicate through shared `.ai/` workspace
2. Updates are documented in relevant files
3. Changes are reviewed by appropriate agents
4. Decisions are recorded in `DECISIONS.md`

### Handoff Protocol
1. Agent completes task
2. Updates documentation
3. Notifies dependent agents
4. Validates changes
5. Approves handoff

### Conflict Resolution
1. Conflicts are documented
2. Chief Architect makes final decision
3. Decision is recorded
4. All agents are notified
