# Analysis HMS - AI Workspace

## Overview

This is the AI-powered development workspace for the Analysis HMS (Hotel Management System) project. It provides comprehensive documentation, knowledge base, and tools for AI coding agents to understand, remember, analyze, and improve the project.

## How to Use

### For AI Coding Agents

1. **Start Here**: Read `SYSTEM_PROMPT.md` to understand your role
2. **Load Skills**: Use the `skill` tool to load relevant skills
3. **Check Memory**: Review `MEMORY.md` for project context
4. **Follow Rules**: Adhere to `CODING_RULES.md` and `BUSINESS_RULES.md`
5. **Update Memory**: Always update memory after completing tasks

### For Developers

1. **Architecture**: Review `ARCHITECTURE.md` for system design
2. **Coding Standards**: Follow `CODING_RULES.md`
3. **Business Rules**: Understand `BUSINESS_RULES.md`
4. **Testing**: Refer to `TESTING.md` for test strategies
5. **Security**: Follow `SECURITY.md` guidelines
