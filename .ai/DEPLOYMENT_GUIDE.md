# Analysis HMS — Deployment Guide

> Production deployment guide for the Analysis HMS Hotel Management System.

---

| Component | Version | Notes |

## Fresh Installation

### 1. Clone & Install

```bash
git clone <repository-url> analysishms
cd analysishms
composer install
```

### 2. Environment Configuration

```bash
cp .env.example .env  # or create .env manually
php artisan key:generate
```

Configure `.env`:

```env
APP_NAME="Analysis HMS"
APP_ENV=production
APP_KEY=<auto-generated>
APP_DEBUG=false
APP_URL=https://your-domain.com

DB_CONNECTION=mysql
DB_HOST=127.0.0.1
DB_PORT=3306
DB_DATABASE=analysis
DB_USERNAME=your_db_user
DB_PASSWORD=your_db_password

# Production hardening
QUEUE_CONNECTION=redis          # or database
CACHE_DRIVER=redis              # or database
SESSION_DRIVER=redis            # or database
SESSION_LIFETIME=120

MAIL_MAILER=smtp
MAIL_HOST=smtp.your-provider.com
MAIL_PORT=587
MAIL_USERNAME=your@email.com
MAIL_PASSWORD=your-password
MAIL_ENCRYPTION=tls
```

### 3. Database Setup

```bash
# Import the database schema
mysql -u root -p analysis < database/analysis.sql

# Or run migrations (if available)
php artisan migrate
```

### 4. Storage & Permissions

```bash
php artisan storage:link
chmod -R 775 storage bootstrap/cache
chown -R www-data:www-data storage bootstrap/cache
```

### 5. Cache & Optimize

```bash
php artisan config:cache
php artisan route:cache
php artisan view:cache
php artisan event:cache
```

### 6. Start

```bash
# Development
php artisan serve

# Production (Apache/Nginx)
# Point document root to /public directory
```

## Multi-Property Setup

The system supports multiple properties. Each property has its own:
- `propertyid` (integer, unique)
- Database records (filtered by `propertyid` column)
- User access (via `users.propertyid`)

To add a property:
1. Insert into `companyreg` table
2. Configure `enviro_general` settings
3. Create user accounts with the property's `propertyid`
4. Set up revenue codes (`revmast`), departments (`depart`), rooms (`room_mast`)

## Production Hardening Checklist

- [ ] `APP_DEBUG=false`
- [ ] `APP_ENV=production`
- [ ] Strong `APP_KEY` (32+ chars)
- [ ] Secure database credentials
- [ ] HTTPS enforced
- [ ] `SESSION_DRIVER=redis` or `database`
- [ ] `CACHE_DRIVER=redis` or `database`
- [ ] `QUEUE_CONNECTION=redis` or `database`
- [ ] File permissions: `storage/` and `bootstrap/cache/` writable by web server
- [ ] Remove `.env` from public access
- [ ] Disable directory listing
- [ ] Configure logging (`LOG_CHANNEL=daily`)
- [ ] Set up automated backups
- [ ] Configure email (SMTP) for notifications

## Backup Strategy

### Database Backup

```bash
# Daily backup
mysqldump -u root -p analysis > backup_$(date +%Y%m%d).sql

# Compressed
mysqldump -u root -p analysis | gzip > backup_$(date +%Y%m%d).sql.gz
```

### File Backup

```bash
tar -czf analysishms_$(date +%Y%m%d).tar.gz \
  --exclude=vendor \
  --exclude=node_modules \
  --exclude=.git \
  analysishms/
```

### Automated Backup (cron)

```bash
# /etc/cron.d/analysishms-backup
0 2 * * * root mysqldump -u root -pPASSWORD analysis | gzip > /backups/analysis_$(date +\%Y\%m\%d).sql.gz
0 2 * * * root find /backups -name "analysis_*.sql.gz" -mtime +30 -delete
```

```bash

php artisan route:clear

```

### Run Tests

```bash
php artisan test
```

### Check Syntax

```bash
# Single file
php -l app/Http/Controllers/Reporting.php

# All controllers
find app/Http/Controllers -name "*.php" -exec php -l {} \;
```

### Nightly Operations

The system has a cron-driven `autoCharge` that posts room charges nightly. Configure:

```bash
# /etc/cron.d/analysishms-nightaudit
0 1 * * * www-data cd /var/www/analysishms && php artisan tinker --execute="app(CronController::class)->autoCharge(request())"
```

## Troubleshooting

| Issue | Solution |
|---|---|
| Blank page | Check `storage/logs/laravel.log` |
| 500 error | Check file permissions on `storage/` |
| Database connection | Verify `.env` DB credentials |
| Session expired | Check `SESSION_DRIVER` and `SESSION_LIFETIME` |
| Cache not clearing | Run `php artisan cache:clear` |
| Route not found | Run `php artisan route:cache` then `php artisan route:clear` |
| Test failures | Check MySQL is running: `netstat -an | grep 3306` |
